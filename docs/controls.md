# Controls

## Touch (landscape)
- **Move**: put your left thumb anywhere on the left side. The stick appears under your thumb.
- **Look**: drag anywhere on the right side.
- **USE** (big button): pick up items, read documents, operate the gate.
- **SPRINT** (hold), **CROUCH** (tap to toggle), **JUMP**, **LIGHT** (flashlight), **FLARE**.
- **BAG** (top right): inventory. **II**: pause and settings.
- Settings: left-handed (mirrors everything), touch button size, look sensitivity, invert Y, vibration, Touch controls Auto/On/Off.

## Keyboard and mouse
| Action | Key |
|---|---|
| Move | W A S D / arrow keys |
| Look | Mouse |
| Sprint | Shift |
| Crouch | Ctrl or C (hold) |
| Jump | Space |
| Use | E |
| Flashlight | F or right mouse button |
| Throw flare | G |
| Inventory | Tab or I |
| Camera view (first/third person) | V |
| Pause | Esc or P |

Input actions are defined in `project.godot`. The touch buttons send the same actions.
